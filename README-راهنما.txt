# MEDLIB — کتابخانه درسنامه‌های پزشکی

## انتشار روی GitHub Pages
1. همه محتویات این پوشه را در ریشه مخزن GitHub خود آپلود کنید.
2. مطمئن شوید فایل `index.html` در ریشه مخزن قرار دارد.
3. در Settings → Pages، گزینه Deploy from a branch را انتخاب کنید.
4. Branch را روی `main` و پوشه را روی `/(root)` بگذارید و Save کنید.

## افزودن درسنامه جدید
1. فایل HTML درسنامه را داخل پوشه `lessons` قرار دهید.
2. در `index.html`، داخل آرایه `LESSONS` یک شیء جدید اضافه کنید؛ نمونه:

```js
{
  title: "درمان پنومونی",
  category: "عفونی",
  description: "تشخیص و درمان پنومونی",
  file: "lessons/pneumonia.html",
  icon: "🫁",
  keywords: "CAP آنتی‌بیوتیک"
}
```

3. تغییرات را Commit کنید. سایت پس از انتشار مجدد به‌روز می‌شود.

## نکته
این نسخه یک سایت استاتیک است و پنل آپلود خصوصی/رمزدار ندارد. مخزن Public یعنی فایل‌های آن عمومی‌اند. اطلاعات شناسایی‌پذیر بیماران را منتشر نکنید.
